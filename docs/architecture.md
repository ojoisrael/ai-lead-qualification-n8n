# Architecture

Tally Trigger
→ HubSpot Create or Update Contact
→ Gemini AI analysis
→ JavaScript parsing
→ Switch: Hot / Warm / Cold
→ Automated follow-up path

## Lead routing

- Hot: immediate Gmail notification
- Warm: wait, then follow-up email
- Cold: nurture email path

The public workflow is a sanitized portfolio version. Reconnect credentials and replace placeholders before using it in a live environment.
